# 盲区 / Blindspot

近未来科幻悬疑解谜游戏。完整网页文件位于 `dist/`。

## 本地运行

在项目目录运行：

```sh
python -m http.server 8000 --directory dist
```

然后打开 http://localhost:8000 。需要通过 HTTP 运行，请勿直接双击 HTML。

四个场景、胶片拍摄与显影、证据推理、两种结局、人物行走动画、AI 头像及低音量合成器背景音乐。无语音播报。进度保存在浏览器本地。

HTML / CSS / JavaScript 原生模块，无安装依赖或构建步骤。美术素材为本项目生成。

已完成代码和逻辑模拟检查，尚未进行浏览器实机画面与音效验证。
